About the app

WobbleTone FX

Build an ordered stack of photographic effects, then save the result as a full-resolution PNG or copy its filter specification.

Private by design

Your photographs stay on this device. WobbleTone processes them locally and does not upload them to a server.

Working with layers

Tap a layer to edit it, use its switch to compare changes, and drag the grip to change the processing order.

Presets and code

Save reusable effect stacks in Presets. The Code tab shows the stack as a Filter Specification — portable JSON the shared engine renders identically everywhere. Build a look here, then import it into Aimless, the no-map walking app that applies these filters to walk photographs.

Backing up presets

Presets live in this browser only. In Presets, Export All saves the whole collection as one JSON file; Import restores it on any device. Share sends the same file through the share sheet. Export on a preset card saves just that one — a handy way to pass a look to a friend or to Aimless.

Installing the app

On iPhone or iPad: open it in Safari, tap Share, then Add to Home Screen, as installed app. On Android: open it in Chrome, tap the menu, then add to home screen/Install app. Installed, it runs full-screen and works offline.
