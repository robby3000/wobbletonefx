About the app

WobbleTone FX

Build an ordered stack of photographic effects, then save the result as a full-resolution PNG or copy a standalone web treatment.

Private by design

Your photographs stay on this device. WobbleTone processes them locally and does not upload them to a server.

Working with layers

Tap a layer to edit it, use its switch to compare changes, and drag the grip to change the processing order.

Presets and code

Save reusable effect stacks in Presets. The Code tab creates HTML and CSS for developers, including an embedded film-grain texture when required.
